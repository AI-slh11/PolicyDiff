Guarantees & Architecture

Five Non-Negotiable Core Principles

Every line of code and algorithm in PolicyDiff is structured around E&O risk mitigation for independent agencies.

01

Every Value Has A Citation

Every extracted limit, deductible, and flagged diff carries exact coordinate citations: document, page number, and bounding box. No citation = not shown.

02

Deterministic Diff Engine

Diffs are calculated in 100% deterministic TypeScript algorithms without LLMs. The LLM only parses initial structured JSON and generates plain summaries.

03

Recall Over Precision

Missing an exclusionary endorsement is catastrophic for agency E&O. PolicyDiff is rigorously tuned for 100% recall on commercial policies.

04

Mandatory Human Sign-Off

The app assists human broker review; it never replaces it. Every critical discrepancy must be accepted or flagged with notes before audit export is unlocked.

05

Strict Retention & Zero Training

Customer policy PDFs are encrypted at rest, auto-purged on schedule (e.g. 90-day retention cron), never logged, and never fed into AI model training.

06

Zero-Gateway Bank Billing

No credit card numbers or processor SDKs stored. Invoices generated automatically with Net-7 bank wire instructions and unique reference tracking.

Technical Foundation

Verified Full-Stack Architecture

Built with Next.js 15, PostgreSQL with RLS, S3 Storage, TypeScript Vector PDF Generators, and Cloudflare Pages.

⚡️ Extraction & Ingestion Pipeline

  • • Dual-Mode Ingestion: Detects existing PDF text layers with coordinates; falls back to OCR for scanned policies.
  • • Pre-Upload Malware Hook: Validates file headers, types, and size limits before storage.
  • • Two-Pass Grounding: Re-reads cited bounding boxes to confirm every value before diffing.
  • • Anti-Hallucination Guard: Rejects any plain-English summary mentioning numbers not in source.

🔒 Multi-Tenant Security & Compliance

  • • Postgres Row-Level Security: Hardware-level tenant isolation preventing cross-agency leakage.
  • • Automated Retention Purge: Daily cron job (retention-cleanup.ts) permanently wipes expired files.
  • • Signed Temporary URLs: S3 storage access restricted to short-lived pre-signed URLs.
  • • Comprehensive Audit Trail: Every sign-off, diff action, payment mark, and invoice logged.
